# Orbit

A quiet field journal for friendships, made with ADHD brains in mind.

- A five-step ladder (Acquaintance, Casual friend, Friend, Good friend, Homie), each defined by Contact, Knowing, Asking and Effort, plus markers (Tempered, Platonic soulmate, Dormant) and Best friend (overarching or of a season).
- One-tap logging of who reached out, with optional details (how, depth, feel, replies, notes).
- Reminders after a set number of days (per tier and per person), snooze, birthdays, calendar file.
- Fair-to-expect lists per tier, Reflect on this friendship, Work through something (conflict gameplan), How you connect (attachment-informed self-check).

Plain static site: `index.html`, `sw.js`, `manifest.json`, icons. No build step. Data stays on the device (localStorage) with backup and restore; the same page also runs as a claude.ai artifact with account sync.
